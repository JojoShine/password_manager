应用会根据 macOS 或 Windows 动态展示数据存放位置。你可以在设置页面直接查看。

设置 → 关于与数据 → 密码数据存放位置
  • A导出备份
    在迁移电脑或卸载应用前，先导出需要保留的密码。
  • B恢复数据
    通过导入功能选择备份文件，将记录重新写入当前密码库。
  • C一键重置
    清理本地密码记录与备份。执行前请确认已保存必要的数据。

Windows

先确定程序长期存放的位置，再开始解压。

  1. 将压缩包放到平时用于存放软件的磁盘或目录。
  2. 在当前位置解压压缩包，然后打开解压后的文件夹。

MAC

macOS

把应用放入系统应用目录，后续从启动台或访达打开。

  1. 下载并解压 macOS 压缩包。
  2. 将密码管理工具拖入本机的“应用程序”目录。
  3. 进入“应用程序”，打开密码管理工具并设置主密码。
浏览器插件请固定存放

下载并解压插件后，建议将插件文件夹与应用程序放在同一管理目录。浏览器会持续读取这个文件夹，移动或误删后可能导致插件失效。

应用安装目录与密码数据目录并不相同。移动应用程序不能代替密码数据备份，换机或卸载前请先使用应用内的导出功能。

FAQ

使用前，了解这些就够了。

密码会同步到云端吗？

不会。应用以本地管理为核心，不要求注册账号，也不会主动把密码上传到云端。

忘记主密码后可以找回吗？

主密码无法通过服务器找回，因为应用没有保存你的云端账号。请妥善记住主密码，并定期导出备份。

为什么浏览器插件显示连接失败？

请先打开桌面应用并完成解锁。插件需要通过本机连接访问密码库，应用退出或锁定后会停止提供密码。

卸载应用前需要做什么？

先导出需要保留的密码备份，再根据应用内“应用卸载流程”的提示处理本地数据目录。
