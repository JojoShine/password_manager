密码记录保存在当前电脑中。应用不要求注册账号，也不会主动上传密码或设备标识。

HOW TO USE

第一次打开，也能很快开始。

创建

设置你的主密码

首次使用时创建主密码。请选一个自己能记住、他人不容易猜到的密码。

收录

添加现有密码

填写网站、账号、密码与分类。也可以先用密码生成器创建新密码。

使用

搜索、查看与编辑

通过标题、网站或分类快速找到记录，按需查看、修改、分享或删除。

备份

定期导出数据

在导入导出页面保存备份。重要密码建议使用加密 JSON 格式导出。

BROWSER EXTENSION

让登录页与本地密码库连接起来。

安装随应用提供的浏览器插件后，可以在登录页面填充密码，并在成功登录后收到保存提示。

CHROME EDGE CHROMIUM
解压

保存插件文件夹

从应用中取得插件包，解压到电脑上的固定位置，不要安装后立即删除。

载入

打开扩展管理页面

开启开发者模式，选择“加载已解压的扩展程序”，然后选中插件文件夹。

连接

保持应用已打开并解锁

浏览器插件通过本机连接访问密码库。桌面应用锁定或退出时，插件不会读取密码。

登录

填充或保存密码

在网站登录页选择已有记录。完成登录后，再根据提示决定是否保存新密码。

连接失败时，请先确认桌面应用正在运行并处于解锁状态，再重新打开插件。

YOUR DATA

知道数据在哪，也知道如何带走。

系统数据目录

应用会根据 macOS 或 Windows 动态展示数据存放位置。你可以在设置页面直接查看。

设置 → 关于与数据 → 密码数据存放位置
  • A导出备份
    在迁移电脑或卸载应用前，先导出需要保留的密码。
  • B恢复数据
    通过导入功能选择备份文件，将记录重新写入当前密码库。
  • C一键重置
    清空密码记录与备份内容，保留原主密码保护的空加密库。执行前请先备份。

VERSION NOTES

版本更新

了解当前版本的变化，以及如何从旧版升级。

3.1.2 · 2026-11-07

优化加密密码库的主密码解锁速度：macOS 和 Windows 改用系统原生实现执行密钥派生，并继续在后台计算。

加密强度和密码库格式保持不变，继续使用 PBKDF2-HMAC-SHA256（600,000 次）与 AES-256-GCM。原主密码和 3.1.1 密码库直接兼容，不需要重新迁移。

3.1.0、3.1.1 用户可在“设置 → 版本与更新”检查并安装。若从未加密旧版升级，仍需先让所有同步设备退出旧版并升级，再解锁迁移。

3.1.1 · 2026-11-05

macOS 和 Windows 密码库默认使用 AES-256-GCM 认证加密，主文件、自动备份与写入临时文件均保存为密文。主密码通过带随机盐的 PBKDF2-HMAC-SHA256（600,000 次）派生密钥，同一个同步库在各设备使用同一个主密码。

3.1.0 用户可进入“设置 → 版本与更新”检查并安装；3.0.0 用户需手动下载安装。所有同步设备应先退出旧版并升级至 3.1.1，再用原主密码解锁迁移，旧版不能继续写入新格式。

历史导出、旧目录副本与云盘历史版本不会自动清理。普通 JSON、CSV 导出仍为明文；本次加密适用于桌面版，不覆盖 Web 和移动端的原有存储实现。

3.1.0 · 2026-11-04

应用和浏览器扩展统一更名为 Lockora，更新图标。支持更改密码库目录，可选择 iCloud 等自己的同步目录；改进重复保存提示、扩展连接恢复与底部显示。

macOS 和 Windows 新增“设置 → 版本与更新”，可检查版本并由用户确认安装，更新包会验证签名。正在编辑、保存或导入导出时会阻止更新退出。

3.0.0 用户需手动安装本版一次，原设置与密码库路径继续保留。3.1.0 尚未启用桌面密码库的默认加密，主密码解锁不等于文件加密。

下载并解压插件后，建议将插件文件夹与应用程序放在同一管理目录。浏览器会持续读取这个文件夹，移动或误删后可能导致插件失效。

应用安装目录与密码数据目录并不相同。移动应用程序不能代替密码数据备份，换机或卸载前请先使用应用内的导出功能。

FAQ

使用前，了解这些就够了。

密码会同步到云端吗？

应用不会把密码库上传到开发者服务器。你可以在设置中选择自己的 iCloud Drive 等同步目录，由对应云盘服务同步加密文件；所有设备使用同一个主密码。

忘记主密码后可以找回吗？

主密码无法通过服务器找回，因为应用没有保存你的云端账号。请妥善记住主密码，并定期导出备份。

为什么浏览器插件显示连接失败？

请先打开桌面应用并完成解锁。插件需要通过本机连接访问密码库，应用退出或锁定后会停止提供密码。

卸载应用前需要做什么？

先导出需要保留的密码备份，再根据应用内“应用卸载流程”的提示处理本地数据目录。
